Complete Start-to-Finish Guide

0:50

Follow the entire Ultimate Joystick setup and operating flow, including a staged frontend game selection and the matching gate splash.

Read complete transcript

Welcome to the complete Ultimate Joystick guide. This walkthrough covers the normal setup and operating flow from opening the program through a safe shutdown.

Chapter one: start and connect. Open Ultimate Joystick and allow the main screen to finish loading. On the Monitor and Test tab, locate the connection area. Use No Hardware Mode only when you are preparing the software without the control system. For normal use, leave that option off, refresh the controller list, select the correct device, and choose Connect. Continue only when the visible status reports the expected ready state.

Chapter two: set the arcade locations. Open Settings and use the Browse buttons to select the MAME application and the folder containing your games. Select the matching XML or custom list only if your setup uses one. Save the selections and wait for the application to return to Ready. Open the game list and confirm that game names are available before continuing.

Chapter three: calibration. Connect and prepare the gate assembly before opening Calibration. Select one player and one gate. Make a small adjustment, observe the result, and stop if anything binds. Set the engaged position, then the released position, and use the visible test controls to check both. Repeat this careful sequence for every required player and gate. Save Calibration only after all items have been reviewed.

Chapter four: input and gate tests. Return to Monitor and Test. Start the joystick test and move one direction at a time. Confirm that up, down, left, and right produce the matching on-screen response. Stop and review the input settings if a direction is missing. Next, select one gate test at a time. Wait for the visible status to finish, return to the released state, and then continue with the next gate.

Chapter five: game assignments. Open Game Management and search for a game. Select the game, choose the gate shape you want it to use, and save the assignment. Repeat for additional games. Search for several completed games and confirm the expected gate appears beside each name. Existing assignments can be selected and changed later.

Chapter six: monitoring and launching. Return to Monitor and Test, confirm the connection is ready, and choose Start Monitoring. Launch a configured game through your normal arcade workflow or the visible launch control. Keep hands away from the joystick while a gate change is in progress. When the ready message returns, play can begin. Stop monitoring before changing settings or using manual tests.

Chapter seven: splash screens. In Settings, open the Splash Screen section and enable the messages you want users to see. Choose an image or message, preview it, and keep the wording easy to read. Confirm the display time and save the selections. Preview the screens again to verify that the image is centered and the message is clear.

Now watch the normal front-end flow. A sample arcade game is selected from the game front end. Ultimate Joystick recognizes the selection and shows a splash naming the game and its assigned gate. The visible gate status changes while the selection is prepared, then the ready message appears. This demonstration shows what the user sees without claiming that physical hardware was moved during this recording.

Chapter eight: troubleshooting and shutdown. Start with the visible status areas. Check power and the cable, then refresh the controller list. Review input settings if joystick directions do not respond. Review the arcade locations if the game list is empty. Stop immediately if a gate cannot move freely. To finish, close the running game, stop monitoring, return to the normal released state when the visible controls allow it, and choose Exit. Wait for Ultimate Joystick to close before disconnecting cables or power.

Quick Guide 9

How to Replace the Servo

1:39

Remove, center, install, teach, and test a replacement servo.

1:39 total
Read transcript

This guide shows how to replace the servo. Remove the old servo, connect and center the new servo, install it into the joystick restrictor gate, teach the two positions, then test the movement.

First, remove the old servo from the joystick restrictor gate. Take out the mounting pins or screws and remove the servo from the gate assembly.

Unplug the old servo from the board, but remember exactly which board pins it used. The replacement servo plugs into the same connection.

Detach the restrictor gate linkage from the old servo before installing the replacement.

Connect the new servo to the same board pins, but do not install it into the restrictor gate yet.

Move the replacement servo to center, which is fifteen hundred microseconds. This centers the servo before the arm is installed.

With the servo centered, install the servo arm.

Now mount the servo into the joystick restrictor gate and reconnect the restrictor gate linkage.

Back in Ultimate Joystick, open the Calibration tab.

The orange Pos2 Default warning means released out is the safe default position.

Click Teach for the replaced servo. Teach mode is where the new servo positions are saved.

Move the servo to the released out position, then set and save Pos2.

Move the servo to the engaged in position, then set and save Pos1.

Test the servo by moving it to Pos1 and back to Pos2. Confirm that the travel is clean before normal use.

Finish by returning to Circle, all position two, so the joystick restrictor gate is left in the released default state.
