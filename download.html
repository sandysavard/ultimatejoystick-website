Checksums and release notes: release page. The app needs no installation: put the file in a folder of its own and run it. Its settings and game mapping are saved next to it.

Windows SmartScreen may show "Windows protected your PC" the first time, because the file is from a small publisher. Click More info, then Run anyway. The checksum on the release page lets you confirm the file is the one we published.

First run, in order

  1. Connect the controller to a USB port. Windows installs the standard USB-serial driver by itself.
  2. Open the app. On the Monitor & Test tab, click Refresh, select the controller, click Connect. Wait for Ready.
  3. Settings tab: Browse to your MAME executable, then to your ROM folder. Save. The game list fills in.
  4. Calibration tab: confirm each servo's in and out position once. The video guide walks through it.
  5. Start Monitoring. Launch games from your frontend as usual. Done.

Requirements

  • Windows 10 or 11, 64-bit. The app does not run on Linux, macOS or Raspberry Pi.
  • MAME installed, and your own ROM files. No ROMs are included or provided.
  • An Ultimate Joystick controller. Without one, the app runs in No Hardware Mode so you can prepare paths and game assignments in advance.
  • Any frontend, or none. The app watches the MAME process, not your menu.
